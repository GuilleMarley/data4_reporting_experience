# Data4 Reporting Experience

Demo participativa del proyecto Green Belt de automatización del Reporting Operativo Data4.

## Estructura
- `index.html`: acceso a la experiencia.
- `presentation.html`: pantalla del presentador.
- `audience.html`: interfaz móvil por rol.
- `assets/`: estilos e imágenes de demo.
- `js/`: lógica de interacción.
- `config.js`: configuración pública del backend realtime.
- `supabase.sql`: esquema para Supabase.

La versión pública usa únicamente datos ficticios o anonimizados. No se publica código productivo de las herramientas ni datos de cliente.
